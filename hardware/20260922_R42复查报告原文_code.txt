### 【P1-1】排查记录 §28.4 把 `80 B` 的镜像增量归因给"两处进镜像的字串"——算术上不可能，且与同轮 `烧录须知` 的 `288 B` 自相矛盾

**我跑了什么**（只读 python，操作数取自 git，不靠我手抄）：


镜像侧读数（`build_r42_try1.log` / `build_r42.log` / `backups/r40_*/`）：

```
成功#1  0x116400 = 1,139,712 B      成功#2(待烧) 0x116450 = 1,139,792 B      R40/R41 冻的 0b8818b7 = 1,139,504 B
两次成功之间 = +80 B       全轮（R41→R42） = +288 B
```

**为什么这算错**：本轮**改到镜像里的字串只有这两只**（其余全是注释），它们净增 **156 + 140 = 296 B**。
`80 B ≠ 296 B`，而且字串只会变长不会缩短 —— 所以 §28.4 那句

> "**两次成功之间只差 80 B**（1,139,792 − 1,139,712）：本轮成功第 1→2 次之间改的东西里，只有**两处进镜像的字串**会变长
> （`axp_panel_power.c:577` 判决尾巴第①档那句、`:652` `s_pp_done` 那档跳过原因那句），其余全是注释"

把 **296 B 的原因** 按在 **80 B 的结果** 上，两头对不上。真正被 296 B 解释的是 **288 B** 那只数，
而它写在同一轮的 `hardware/烧录须知.md:469`：

> "它比上一只（R40 冻的 `0b8818b7…`）大 **288 B**（1,139,792 − 1,139,504）"

⇒ **同一轮、同一对字串、两个文档给出两个"原因数"（80 与 288），至少一句是错的。**
按 `git show HEAD~1..HEAD` 可核的事实：288 B 那句方向正确（296 B 字串增量 ≈ 288 B 镜像增量，差的是 `s_pp_done`
搬家带来的 .text 微调与 4 字节对齐），80 B 那句是**把轮内第二段增量当成了全部字串增量**。
符号定位（不用行号当唯一锚）：`bb_pp_scan_all()` 判决 `?:` 链第①档字面量、`bb_probe()` 里 `pp_skip` 链中
`s_pp_done ? …` 那一支字面量。
**修法**：§28.4 那句改成"两次成功之间 +80 B 是 `s_pp_done` 置位点搬家那一次编辑的净效果；
两只字串共 +296 B 落在**全轮 +288 B** 里（见【〇】待烧段）"。

### 【P2-2】把 `0.47` 说成"当年母数 / 一个世代"，与**同一只文件** `:124` 已确立的"`0.47` 是分项和不自洽"冲突 ⇒ 真实缺额是 `0.27 = 0.26 + 0.01`

本轮新增（`epd_driver.c`，同一块注释）：

```
 *   缺多少要看母数：当年母数 AXP=0.47 ⇒ 差 **0.26**；现行母数（B1=0.46 / B2=0.73）⇒ 差 0.27。
 *   ⇒ 谁要"补 14.07"只能用 0.26（14.07+0.26=14.33 闭合）；拿 0.27 去补会得 14.34，
 *   那是把两个世代的母数混在一支加法里。
```

而**同一只文件里 `probe_attempt()` 分支表 B1 那一格**（R41 落、本轮没动）说的是另一回事：

```
 *          **0.47s**，而它自己给的分项和是 **0.46** —— 正是下面 B2 那一格"算式与它自己给的结果不等"
 *          的第三个实例；要么把 PWR 读补成含一次 `gpio_config` 的 0.02，要么全族改 0.46。
```

**为什么这算错（措辞层面）**：`0.47` 不是"一个旧世代的母数"，它是**同一批分项算错/口径未定而留下的 1 分钱误差**，
R41 已经把它订到 `0.46`。所以：
- 物理缺额（B2 − B1_现行）= `0.73 − 0.46` = **0.27**；
- 账面上补 `14.07` 只用 **0.26**，因为 `14.07` 这个历史字串里**多含 0.01 的当年误差**（`0.47 − 0.46`）。

我重算过两头：`0.26 + 0.01 = 0.27` ✓、`14.07 − 0.01 = 14.06 = 0.46+0.05+2.75+2.75+0.05+8` ✓。
⇒ 本轮的"只能用 0.26"作为**记账口径**是对的、算术全对，但"两个世代的母数"这个说法**把一次自己的加法事故
洗成了口径换代**，读起来像在说 `0.47` 曾经合法。`eink_display.c:540-543` 同族表述更强（"缺的**只有** B2 那 0.26s（不是 0.27）"），
它后面虽有"0.27 是现行母数下的 B2−B1"，但没有交代那 0.01 从哪来。
**修法**：两句都补半行 —— "差的 0.26 = 现行 0.27 − 当年 B1 多记的 0.01（R41 已把 B1 从 0.47 订到 0.46）"。
