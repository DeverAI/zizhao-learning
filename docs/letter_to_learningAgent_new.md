# 致学习Agent_new：自招素材系统对贵仓资料/记忆的调用告知

> 发件：自招学习 / 自招素材系统后端  
> 仓库路径：`自招学习/backend`（本机相对布局，不在公开仓暴露绝对路径）  
> 日期：2026-09-12  
> 性质：跨仓只读共享告知（非合并、非 fork、不要求贵仓改代码）

---

## 一、我们是谁

我们不是来抢职责的第二套学习搭子。  
我们是**上海中考自主招生**场景下的**每日素材终端后端**：

- 每天一条可听可读的自招素材（哲学 / 历史 / 高中古诗文 / 课程体系「自招」band）
- 素材挂载式对话、去重归档、断点续播

贵仓一句话仍是：初三知识补漏 + 中考主链路。  
我们补的是自招拔高层，不是替代 OCR/题库/专注模式。

---

## 二、我们会调用什么（只读清单）

| 资源 | 路径（相对贵仓 backend） | 怎么用 |
|------|--------------------------|--------|
| 课程体系 | `data/curriculum_cn_junior.json` | 抽取 `band=自招` 等节点灌入计划表 |
| 知识树 | `storage/knowledge_tree.json` | 关键词检索，给 Agent 工具用 |
| 海马体记忆 | `hippocampus/profile.json` | 读掌握度/薄弱点，注入生成与对话 |
| 设置/密钥 | `settings.json` | **仅**读 API Key/BaseURL/Model；不写回、不打印明文、不提交进公开仓 |

**不会做的事：**

1. 不写、不删、不迁贵仓任何业务数据与数据库  
2. 不把贵仓 `app.db`、题目、笔记、会话原文整包拉进 prompt  
3. 不在无密钥时伪造「模型已成功」  
4. 不把贵仓密钥写进我们的仓库、日志、前端  

用户反馈增量只写本地 `storage/memory_delta.json`，**不直接回写**海马体。

---

## 三、为什么要借资料与记忆

自招素材若每天模型自由发挥，必然重复、漂移。  
借贵仓：选题不漂（大纲）、难度贴人（掌握度）、去重有据（指纹+硬键）。

---

## 四、Agent 调用约定

- 共享根：默认同级目录 `学习Agent_new`（可用环境变量 `ZIZHAO_SHARED_ROOT` 覆盖）  
- 桥接：`backend/services/agent_bridge.py`  
- 工具：`search_shared` / `read_shared_excerpt` / `calculator` / `profile_note` 等  
- **先搜再读、限量摘要、带出处路径**，禁止一次倾倒全仓  

若贵仓加一行 `SHARED_ACCESS: denied` 或改名 `*_REVOKED.md`，我方应停止读取。

---

## 五、人格与输出硬约定

1. 不讨好  
2. 情绪支持仅限绝望档  
3. 催做事，落到下一步与交卷点  
4. 渐进画像，不表演人格  
5. **前台无 Markdown**（防 `**` 被显示成「美元美元星号」）
