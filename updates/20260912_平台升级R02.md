# 平台升级 R02：鉴权 + 多组件 + 常驻资料/时间表/媒体（2026-09-12）

## 做了什么

1. **鉴权**
   - 邮箱验证码（未配 SMTP 时写 `storage/email_outbox.json`，不入库 git）
   - PassKey 注册/登录（简化 challenge 流；完整 WebAuthn 可后续加强）
   - **ESP-S3 设备 PassKey**：`POST /api/auth/device/provision` 一次性下发，烧录后 `device/login` 换 sid
   - **sid Cookie**（HttpOnly + HMAC 签名 `sid.sig`）

2. **安全**
   - 全局/登录/上传限流（防 DDoS 粗挡）
   - 邮箱/文本消毒、拒绝路径穿越
   - SQL 全参数化；session_id 白名单
   - 修正 `_access_denied`：只认独立一行 `SHARED_ACCESS: denied`（原先误伤说明文字）

3. **多组件主页**
   - 内置：home / zizhao / english / classics / timetable / library / devices
   - 登录后可启用组件、申请新组件
   - 前端 SPA：`backend/static/{index.html,app.css,app.js}`（触屏可用大热区）

4. **不依赖邻仓的能力**
   - 时间表 CRUD + 文本批量整理
   - 常驻资料库（note/classics/source）
   - 上传：TXT/PDF/DOCX 抽文本；图片 OCR（无 tesseract 则 degraded）
   - TTS-MP3（有共享小米密钥则生成，否则 degraded，不伪造）

5. **Agent 工具扩展**
   - `timetable_read/write` · `resident_search/add`（仍保留邻仓 search_shared）

## 测试

`python -m unittest test_platform test_material_system test_audit_fixes test_agent_stack` → **25 passed**

## 设备对接（ESP-S3 微雪）

```
1) 网页登录 → 设备页 → 签发 PassKey
2) 固件烧录 device_id + passkey
3) POST /api/auth/device/login {device_id, passkey} → sid
4) 后续请求带 Cookie zsid=<sid.sig> 或 X-Zizhao-Sid
```

## 未尽事项
