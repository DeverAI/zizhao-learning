## 英语组件

| 能力 | API |
|------|-----|
| 抽卡 | `GET /api/english/card?bank_id&mode=en2cn|cn2en&source=new|wrong|mixed` |
| 会/模糊/不会 | `POST /api/english/grade` |
| 模糊名句二选一 | `GET /api/english/vague?word=` |
| 错词库 | wrong bank；known 自动移出 |
| 新库 | source=new：排除已会与错词，按频次 |

## 小工具

- `POST /api/tools/calc` `{text}` 或 `{audio_base64}` → expression → value  
- `POST /api/tools/explain_question` 核心干路 +「对吗？」  
- `POST /api/tools/explain_confirm` 麦克风语义：对 / 问题
