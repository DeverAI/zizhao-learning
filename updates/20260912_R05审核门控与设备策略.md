# R05：审核门控 / 开关机 / 现场配网 / 自注册 API（2026-09-12）

## 产品语义修正（按用户澄清）

**每日审核 ≠ 写完就过。**  
每个用户当日素材必须 **多轮挑刺**（规则底线 + LLM 找茬）→ 有刺改写再审 → **挑不出** 才 `review_status=passed`。  
**只有 passed 才允许生成/下发音频**；离线包 `audio_ready` 为 false 时板子禁播。

## 新增/改动

| 项 | 说明 |
|----|------|
| `review_service.run_review_loop` | max_rounds 默认 4；历史写入 `storage/reviews/day/user.json` |
| `materials.review_status/rounds/note` | pending/passed/failed |
| `POST /api/review/run` · `GET /api/review/today` | 手动触发与查询 |
| 离线包 | 未过审：`audio_segments=[]` + `audio_blocked_reason` |
| 夜间 | 审核全用户 → passed 再 TTS |
| 自注册 API | `/api/settings/apis/{text,tts}` OpenAI 兼容；probe；生成/对话/TTS 优先用户 Key |
| 开关机策略 | `/api/device/power`；默认 04:30 关 / 06:00 开 / 开机 15min 无活动再关 |
| 现场配网 | AP `Zizhao-Setup-*` 门户约定 + `POST /api/device/onsite-config` 校验设备归属 |
| ESP 骨架 v2 | `hardware/esp32s3_firmware_skeleton.md` + `esp32_main_skeleton.c` |
