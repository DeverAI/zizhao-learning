# R04 三人分用隔离 + 完成度（2026-09-12）

> 需求：做完&安全；三人用、数据分开；素材可靠小米模型搜索，不靠扩静态大纲。

## 本轮隔离了什么

| 资源 | 之前 | 现在 |
|------|------|------|
| 用户画像/人格 | **全局一份** | `storage/profiles/{user_id}.json` |
| 今日素材 | **全局一份** | `materials.user_id` 按人各一条 |
| 聊天会话 | 前端写死 `web` 串号 | 登录后自动 `{user_id}:web` |
| memory_delta | 全局 json | `storage/memory_delta/{user_id}.json` |
| 上传列表 | 全局 index | 按 `user_id` 过滤；目录 `uploads/{uid}/` |
| feedback | 可写他人 | 403 if 素材属于别人 |
| quiz | 用全局今日 | 用本人今日；跨人素材 403 |

## 额外修掉的坑

1. `DEFAULT_PROFILE` 浅拷贝 → 嵌套 list 三人共享（P0 隐私）  
2. `asyncio.Lock` 跨 `asyncio.run` 死锁 → 改 `threading.Lock`  
3. 关闭 LLM 时仍可能打小米搜索 → 与 `ENABLE_LLM_GENERATION` 联动  

## 小米搜索

- `get_ai_credentials` 增加 `xiaomi`（token-plan）  
- `xiaomi_web_search`：生成素材前注入检索摘要（失败返回空，不伪造）  
- 仅 `ENABLE_LLM_GENERATION=True` 时调用  

## 安全（三人场景）

- sid 必须带 HMAC；PassKey 必须验签（R03）  
- 业务接口依赖 Cookie；上传/小测/画像必须登录  
- 限流 auth/upload/default 分桶
